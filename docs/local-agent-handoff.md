# 给本地 Codex / 其他助手的接手模板

[返回 README](../README.md)

以下提示词用于你自己的电脑。先确认应用具有本地工具权限；普通网页聊天不能直接配置系统。不要把真实秘密补进这份公开文件。

---

请先阅读本仓库 README、固定出口、AdsPower、平台和验收文档，再检查本机环境。

目标是使用我已授权的中转与固定出口，保证选定应用/公网业务 TCP 的出口一致。出口目标和凭据从本机客户端或安全存储读取，不在回复、日志、仓库或截图里打印。

先只读确认操作系统、代理客户端/内核、实际端口、TUN、DNS/IPv6、其他 VPN、管理员/组织策略和远程访问依赖。确认是原生运行、WSL 还是容器，分别验收。

我会选择“应用使用本机 HTTP”或“应用自己配置远端 SOCKS5”其中一种。第二种只为连接该 SOCKS5 服务器的准确 IP + TCP 端口设置中转例外，不让应用的所有网站流量直接从中转出口出站。

实施前备份并给出回滚方法。保留既有账号、hooks、权限、插件和用户规则；说明哪些分流设置会被固定出口模式替换。不要升级软件、购买服务、改出口、共享账号或伪造设备指纹。

先验证代理入口，再最小合并配置。用实际内核做语法检查，加载后检查运行态连接和真实回显。节点缺失不得改成 DIRECT 或其他出口。配置检查失败时暂停部署，不能假定旧配置已经被阻断。

系统断网保护必须按本机适配，先确认现场可恢复，并建立、验证独立自动撤回机制；不要依赖助手会话中的定时器。使用正常管理员授权，不规避 GPO/EDR，不切断唯一远程通道，不全局清空防火墙。

最后在私有报告中区分已检查、已修改、已验证和未验证，记录精确备份/回滚位置。网络通不等于账号可用，短测不等于长期稳定；Windows 和 WSL 的结果也不能相互替代。
