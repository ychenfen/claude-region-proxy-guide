# 固定出口、DNS 与系统保护

[返回 README](../README.md)

## 先确定目标

本文模板选择：普通公网 TCP 固定走指定出口；不能验证或无法经该出口转发的公网 UDP、IPv6 先拒绝。不是“所有协议都变成美国地址”，不适合不经评估就用于语音、游戏或依赖 UDP 的远程工具。

回环、示例中的私有网段和链路本地通信仍保留；连接中转和引导 DNS 是明确例外。不能宣传“每个底层包都只经过最终出口”；允许局域网也不能防止另一台局域网代理再次转发。

## 应用入口

Claude Code 应连接支持的本地 HTTP/HTTPS 代理，再由内核连接 SOCKS5，不把远端 SOCKS5 URI 直接当作 HTTP 代理。

[claude-env.json](../examples/claude-env.json) 只是 env 合并片段，不是完整 settings.json。先验证入口，再备份合并；保留 hooks、权限、插件、认证和其他环境变量。

检查启动器、项目级、受管配置的覆盖关系；在不打断工作的时机重启会话。不要绕过组织策略或关闭 TLS 校验。Windows PowerShell 5.1 的 JSON 往返可能无法保留大小写不同的同名键，使用合适的 JSON 工具。WSL/容器的回环地址另行验证。

## 各协议分别验证

| 项目 | 实施意图 | 不能据此推断 |
| --- | --- | --- |
| DNS | 业务 DoH 经固定组，TLS 校验开启 | 系统 DNS 列表不证明实际请求路径 |
| 引导 DNS | 用可达的 HTTPS 解析器解析中转主机，避免循环依赖 | 它是物理出站例外，不是普通业务 DNS |
| UDP | 未验证端到端支持时拒绝公网 UDP | timeout 也可能是目标不可达 |
| IPv6 | 保留接管，并拒绝公网 IPv6 字面地址 | 禁止 AAAA 不等于禁止 IPv6 |
| WebRTC | 检查实际浏览器的 STUN / ICE 候选 | host/mDNS 不自动等于泄露；无候选也不必然安全 |

模板保留现有 TUN 的开关、设备与栈。必须检查路由/进程排除、额外监听器、其他 VPN 和 GUI 覆盖；脚本加载成功不等于整机接管。

## 失效时不直连：需要操作系统保护

TUN、strict-route、REJECT 都不等于代理退出后仍有效的系统级保护。

macOS 可使用独立 PF 策略；Windows 需要原生防火墙/WFP 或经验证的客户端机制。**本仓库没有一键全局防火墙安装器**：接口、远程访问、已有策略与恢复条件各不相同，盲用可能锁死网络。

实施前必须：

1. 确认能本机恢复，不会切断唯一远程通道。
2. 备份现有策略，准备只恢复本轮改动的恢复脚本。
3. 正常授权，设置独立于 Codex/联网的自动撤回机制，并实际验证能执行。
4. 限定中转地址、端口、程序、引导解析例外，考虑域名地址变化。
5. 正向验证后，受控关闭 TUN/代理做负向对照；恢复成功后才提交保留。

Windows 显式 Block 通常优先于 Allow，不能“全公网 Block 再补 Allow”照搬 PF。仅设置默认出站 Block 也不够，已有宽泛 Allow 可能仍然有效。不能清空组织规则或放行所有程序/所有公网 UDP 来修通。

重启、唤醒、切网、客户端退出、配置重生成、长连接和晚高峰分别验收。管理员及高权限软件可改变策略，不能宣称绝对不可绕过。

详细检查项见 [验收与隐私清单](verification-and-privacy.md)。
